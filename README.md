# content-rot has moved to [derived-total](https://github.com/MohitPratapSinghRathore/derived-total)

This repository was renamed. Everything, the code, the result files, the macro
provenance records and the manuscripts, is at:

**https://github.com/MohitPratapSinghRathore/derived-total**

GitHub forwards the old URL automatically, so existing clones and links keep
working. This placeholder exists so that the old name is not free for someone else
to claim, and so anyone who reaches it by an old citation lands somewhere that says
where to go.

The name changed because the work changed. `content-rot` described an early framing
about state decaying over long generations. What the project now argues is narrower
and more useful: when a measured total is decomposed into categories and each is
fitted separately, the total must be **derived** from the parts rather than fitted
alongside them, because a sum of power laws with differing exponents is not a power
law.
